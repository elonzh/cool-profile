# Cool Profile

[English](README.en.md)

把动态信息变成图片与动画，嵌入个人主页、README 和网站。

首期围绕 GitHub 和 CNB 数据，计划提供贪吃蛇、太空射击、3D 活跃日历和统计卡片。后续可接入 B 站粉丝数、Steam 信息等数据源。

媒体内容支持多语言，默认中文，并提供多种主题效果。

## 使用方式

计划提供 CLI 批量生成文件，也可通过 CNB 插件和 GitHub Action 自动更新。后续增加 server 模式，通过 URL 直接获取图片。

项目处于初始化阶段，生成器尚未发布。[查看架构草案](docs/architecture.md)。
